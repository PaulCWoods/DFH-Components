Everything you need to build with Design For Humans is free, for any project, commercial ones included. The paid parts are for designers who work in Figma and for teams that run several brands.

## Free, under the MIT licence

The MIT licence lets you use, change and share the code, in any project, as long as the licence notice stays with it.

- **The CSS library:** every component, layout primitive and utility, with its tokens, and the published stylesheets you can link from `components.designforhumans.blog/css/<version>/`.
- **The theme engine:** it builds a theme into tokens, checks every gate (contrast, the type scale, target sizes), and makes sub-brands scoped to a class.
- **The theme format:** the [theme schema](/schema/theme-v1.schema.json), so any tool can read, write and check a theme.
- **These docs and Storybook:** every component, variant and state, with axe checks on each.
- **The skills for AI agents:** six [skills](/docs/start/skills/) that teach a coding agent to build with the library, versioned with the CSS.

The source goes public on GitHub with version 1.

## Planned

The Token Designer and the Figma kit aren't released yet. Prices come with each launch.

| Tier | What it adds | Paid |
| :--- | :--- | :--- |
| **Free Designer** | The [Token Designer](/docs/tools/) in your browser: edit one theme, with its live preview, Real World pages and every check, and download its CSS. Your work stays on your device. | No |
| **Figma kit** | Every component in Figma, built on variables with light and dark, type sizing, spacing and pointer modes, and whole example pages. | Once, with updates for life |
| **Pro** | For agencies and multi-brand teams: sub-brands and several themes in the Designer, the [Figma export](/docs/tools/figma/) of your own themes, themes drafted by AI and checked by the gates, and an accessibility report a client can sign off. | A subscription |

The paid parts never change what's free. A theme made with Pro builds with the free engine, and its CSS works with the free library.
