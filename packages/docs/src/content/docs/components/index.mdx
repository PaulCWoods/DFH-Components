Every component is a class (or a few) on native HTML. They are grouped by size, and each tier is built from the ones below it: a card holds headings, text and buttons; a dialog holds a card. The bigger parts arrange the smaller ones and leave their styling to them, so a button looks the same in a card, a dialog or a toolbar.

Components share the same options wherever they make sense: size (`--sm`, `--lg`), prominence (`--strong`, `--subtle`, `--plain`), intent (`--accent`, `--danger` and the rest) and density (`--compact`). Each option changes one thing, so they combine freely.
