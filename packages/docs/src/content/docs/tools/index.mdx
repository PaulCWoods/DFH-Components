The library comes with three tools beside these docs. Each one works from the same tokens.

## Storybook

The workbench. Every component has stories for each variant, size, state and edge case (right-to-left text, compact regions, long content), and each story runs axe accessibility checks as it renders.

Use it to see everything a component can do, or to check a change. These docs show the common cases and link to [Storybook](/storybook/) for the rest. In a clone of the repository, `npm run storybook` runs it on your own computer.

## Token Designer

The theme editor, free in your browser at [designer.designforhumans.blog](https://designer.designforhumans.blog/). It edits a theme visually: colour ramps and roles with their contrast, high contrast, the type scale and text styles, spacing, shape, motion and each component's tokens. A preview shows the result, and each change runs the same checks as the library's build.

It exports the theme as a file to keep with your code and a stylesheet to link after the library. [Working with the Token Designer](/docs/tools/designer/) walks through the round trip. More themes, sub-brands and the Figma export are part of [Pro](/docs/start/free/#pro).

## Figma

The [Figma kit](/docs/start/free/#the-figma-kit) has every component, built on the library's tokens as Figma variables, with light and dark, type sizing, spacing and pointer modes. With Pro, the Token Designer exports your own theme to Figma variables and Tokens Studio, so the kit wears your theme. [Figma](/docs/tools/figma/) walks through both.
