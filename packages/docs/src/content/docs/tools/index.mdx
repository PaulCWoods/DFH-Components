The library comes with three tools beside these docs. Each one works from the same tokens.

## Storybook

The workbench. Every component has stories for each variant, size, state and edge case (right-to-left text, compact regions, long content), and each story runs axe accessibility checks as it renders.

Use it to see everything a component can do, or to check a change. These docs show the common cases and link to Storybook for the rest.

```sh
npm run storybook        # http://localhost:6006
```

## Token Designer

The theme editor. It edits a theme visually: colour ramps and roles with their contrast, high contrast, the type scale and text styles, spacing, shape, motion and each component's tokens. A preview shows the result, and each change runs the same checks as the build.

Themes live in `tokens/themes`, one file each. The default, the starter theme, builds the library's own tokens. Every other theme builds a stylesheet in `packages/css/src/themes` holding only what it changes. Pick the one to edit from the menu under the logo, then one of its [sub-brands](/docs/start/themes/#sub-brands), or start a new one.

Each theme file names its format with `"$schema"` and `"version"`, so an editor that reads JSON Schema checks and completes it as you type. The [theme schema](/schema/theme-v1.schema.json) is public: other tools can read and write themes too. Every theme is checked against it before it's built, and a problem names where it is: `type.scale.ration isn't part of type.scale`.

**Publish** writes the theme, rebuilds every theme's CSS and exports to Figma. It is blocked while any check fails. `npm run build:themes` does the same from the command line.

```sh
npm run designer         # http://localhost:5180
```

## Figma

`npm run export:figma` writes the tokens for Figma in two forms: Tokens Studio (free tier), and native Figma variables in light and dark modes, with text styles generated from the same type theme as the CSS. [Using the Figma exports](/docs/tools/figma/) walks through importing them and which set suits each Figma plan.

```sh
npm run export:figma     # packages/figma-sync/dist/
```
